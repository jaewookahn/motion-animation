# fonts

모든 작품이 `../../fonts/`(버전 파일은 `../../../fonts/`)로 참조합니다. 원본 파일을 수정 없이 재배포하며, 라이선스 원문은 `licenses/`에 있습니다.

| 파일 | 폰트 | 라이선스 | 출처 |
|---|---|---|---|
| Pretendard-{Black,ExtraBold,Bold,SemiBold,Medium}.otf | Pretendard | SIL OFL 1.1 | github.com/orioncactus/pretendard |
| HackNerdFontMono-{Regular,Bold}.ttf | Hack Nerd Font Mono | MIT (Hack) + Nerd Fonts 라이선스 | github.com/source-foundry/Hack, github.com/ryanoasis/nerd-fonts |
| BlackHanSans-Regular.ttf | Black Han Sans | SIL OFL 1.1 | Google Fonts |
| Gaegu-Bold.ttf | Gaegu | SIL OFL 1.1 | Google Fonts |
| NanumPenScript-Regular.ttf | 나눔손글씨 펜 | SIL OFL 1.1 | Google Fonts |

합계 약 19MB. 폰트 파일이 없어도 각 `index.html`은 대체 폰트로 재생됩니다(글자 모양만 달라짐).
