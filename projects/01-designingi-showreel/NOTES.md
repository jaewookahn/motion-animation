## 3. 기술 구성
- **렌더러**: `index.html` — Canvas 2D, 결정론적 `frame(t)` 함수(프레임 단위로 정확히 재현됨). 브라우저로 열면 실시간 루프 재생.
- **카메라/후처리**: 비트 히트 기반 셰이크·줌 펀치, RGB 색수차, 슬라이스 글리치, 비네팅, 플래시, HUD(타임코드·씬 라벨·진행바).
- **모션 블러**: 120fps 캡처 → `tmix` 2프레임 합성 → 60fps (180° 셔터 효과). 필름 그레인은 ffmpeg `noise`.
- **사운드**: `audio.py` — numpy로 전부 합성(킥/클랩/하이햇/베이스/패드/라이저/임팩트/UI 클릭). 모든 효과음이 화면 이벤트 시각과 동기화됨. 라우드니스 −14 LUFS 정규화.
- **폰트**: Pretendard(900/800/700/600/500), Hack Mono.

## 4. 파일
