# 윤동주 — 서시 (序詩) 모션 그래픽 (별자리 지도 스타일)

- 프리셋 스타일: `STYLE_LIBRARY.md` **G. 별자리 지도** (Constellation Map)
- 대상: 윤동주 시인의 《서시》(1941. 11. 20.)
- 재생 시간: 16초 (`DUR = 16.0`)
- 기술: HTML5 Canvas 2D, 결정론적 `frame(t)`

## 비주얼 구성 (시상 전개)
1. **0.0–3.5s [하늘을 우러러]**: 깊은 밤하늘과 북두칠성 별자리 드로잉. "죽는 날까지 하늘을 우러러 / 한 점 부끄럼이 없기를,"
2. **3.5–7.0s [잎새에 이는 바람]**: 화면을 가로지르는 바람의 유선과 흔들리는 나뭇가지 실루엣. "잎새에 이는 바람에도 / 나는 괴로워했다."
3. **6.8–10.5s [별을 노래하는 마음]**: 리라(거문고) 별자리와 가장 밝은 별(직녀성/Vega)의 십자 발광. "별을 노래하는 마음으로 / 모든 죽어가는 것을 사랑해야지"
4. **10.2–13.2s [주어진 길]**: 밤하늘 아래 언덕 지평선과 등불을 들고 묵묵히 걸어가는 뒷모습 실루엣. "그리고 나한테 주어진 길을 / 걸어가야겠다."
5. **12.8–16.0s [별이 바람에 스치운다]**: 밤하늘을 가르는 서정적인 유성(별똥별), 윤동주 시인의 붉은 전각 낙관(도장)과 집필 연도. "오늘 밤에도 별이 바람에 스치운다."
