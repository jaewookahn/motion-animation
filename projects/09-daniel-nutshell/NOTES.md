## 07에서 바꾼 점
| 07 | 09 |
|---|---|

## 카메라 동선
| 시간 | 카메라 | 내용 |
|---|---|---|
| 0–2.9 | 도시 전경 → 다니엘 집 창문으로 푸시 | 황혼, 창문을 열고 무릎 꿇어 기도. 신하 셋이 엿봄 |
| 3.0–5.0 | 궁전 | 다리오 왕과 칙령 두루마리(기도 → 사자굴 아이콘, 붉은 도장) |
| 5.0–6.4 | 굴 입구 → 수직 하강 | 밤, 밧줄로 내려지는 다니엘, 돌로 막고 왕의 도장 봉인 |
| 6.4–8.0 | 사자굴 | 어둠 속 빛나는 눈 → 다가오며 으르렁 |
| 8.0–10.3 | 사자굴 | 빛기둥과 천사, 사자들이 입 다물고 엎드려 잠듦, 다니엘 기도 |
| 10.3–12.9 | 상승 → 지상 | 새벽, 왕이 달려와 부름, 돌을 치우고 다니엘을 끌어올림 (단 6:23) |
| 12.9–15 | 전체 단면도로 줌아웃 | 제목 + 시리즈 붉은 낙관 |

## 기법
- 월드 좌표 한 장(지표 y=2000, 사자굴 중심 y=2760) + 키프레임 카메라(eInOutCubic, 줌은 1/z 보간)
- 원경 산·도시는 시차(parallax) 레이어, 하늘·건물 색은 `night(t)`로 혼합
- 사자굴 조명: 어둠 오버레이 → 빛나는 눈은 오버레이 위에 다시 그림 → 천사 빛은 `lighter` 합성
- 주석 콜아웃은 월드 좌표를 화면 좌표로 바꿔 화면 공간에 그려 줌과 무관하게 같은 크기
