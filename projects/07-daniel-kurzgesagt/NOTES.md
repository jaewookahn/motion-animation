# 다니엘과 사자굴 — 쿠르츠게작트 스타일 (Kurzgesagt in a Nutshell)

- 레퍼런스: [Kurzgesagt – In a Nutshell](https://www.youtube.com/watch?v=5_Fayfx2NUM)
- 대상 이야기: 성경 다니엘 6장 (다니엘과 사자굴)
- 형식: 1920×1080 · 15초 · HTML5 Canvas 2D 웹 실시간 재생 (`DUR = 15.0`)

## 쿠르츠게작트 시각 스타일 구현 특징
1. **네온 & 비비드 플랫 컬러**:
   - 딥 스페이스 퍼플(`#0B061A`, `#1F0E42`), 네온 시안(`#00F5D4`), 핫 핑크(`#F72585`), 네온 옐로우(`#FEE440`), 선명한 오렌지/레드.
   - 공간감을 극대화하는 깊은 방사형 네온 그라디언트와 비네팅.
2. **캐릭터 디자인**:
   - **다니엘**: 쿠르츠게작트의 상징적인 시그니처 옐로우 버드(Duck) 캐릭터에 현자의 보랏빛 로브와 청록색 머플러를 두름.
   - **사자들**: 둥글둥글한 기하학적 형태의 풍성한 오렌지색 갈기, 호기심 어린 눈망울, 천사가 나타나면 온순한 고양이처럼 '식빵 굽기(Loaf)'와 Zzz 수면 모드로 전환.
   - **천사**: 황금 링 후광과 사이버틱한 기하학적 날개, 보호 광선 빔을 방출하는 초월적 존재.
3. **인포그래픽 HUD / 과학적 팝업 카드**:
   - `[ROYAL DECREE #6: PRAY ONLY TO THE KING]`
   - `[SURVIVAL CHANCE: 0.00%]` → `[DANGER INDEX: 999.9%]`
   - `[ANGEL PROTOCOL: LIONS.EXE SHUT DOWN]`, `[THREAT: 0% · CAT PURRING MODE]`
   - `[DAMAGE TAKEN: 0 HP · FAITH LEVEL: 100%]`
4. **탄력적인 모션 (Elastic / Overshoot Easing)**:
   - 스케일 팝인, 탄력 있는 바운스 드롭, 쿠르츠게작트 특유의 눈 깜빡임(Blink) 애니메이션.
5. **시리즈 붉은 낙관**:
   - 쿠르츠게작트 배지 형태의 붉은 헥사곤(Hexagon) 전각 스탬프 (`DAN 6:22`).
